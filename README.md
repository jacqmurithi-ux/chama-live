# Chama Live V1

Clean mobile-first frontend foundation connected to the existing Supabase project.

## Phase 1
- Login
- Create group
- Chairperson activation
- Clean session handling
- Dashboard foundation
- Netlify clean routes

## Deployment
Publish the repository root on Netlify. Keep `netlify.toml` at the repository root.

## Supabase
The frontend uses the publishable Supabase key. It does not contain the service-role key.
